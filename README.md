# ROLEX | The Submariner Showcase

A high-end, cinematic scrollytelling experience built with Next.js and Canvas API. This project features a 265-frame image sequence of the Rolex Submariner, driven entirely by the user's scroll.

## Features
- **Cinematic Scrollytelling**: 265+ high-resolution frames rendered via Canvas for 60fps performance.
- **GPU Accelerated**: Uses `ImageBitmap` for off-thread image decoding.
- **Luxury Aesthetic**: Premium gold typography (Playfair Display) and editorial layout.
- **Dynamic Overlays**: Contextual information that responds to the watch's movement.
- **Mobile Optimized**: Fully responsive navigation and touch-friendly scrolling.
- **Interactive Elements**: Custom liquid cursor and animated UI components.

## Technical Stack
- **Framework**: Next.js 14
- **Animation**: Framer Motion
- **Rendering**: HTML5 Canvas API
- **Styling**: Tailwind CSS

## Deployment
This project is optimized for deployment on **Vercel**.

1. Push to your GitHub repository.
2. Connect the repository to Vercel.
3. The build command `npm run build` will handle everything.
